{% comment %} Progress art — the hidden picture that draws itself as the student answers. Include this wherever a student works through a numbered set of questions and pass a `progress_art` context dict built by ``classroom.progress_art.context()`` (optionally with a `scope` key, see below). The partial renders nothing at all when that dict is missing, so a page that has not opted in is unaffected. Two ways it learns about progress: * One question per page (topic quiz, worksheet session): the server's `done` is already right on every load. The topic quiz additionally calls ``ProgressArt.set(n)`` as each answer is graded so the drawing grows without waiting for the next page. * Every question on one page (homework, mixed quiz): set `scope` to a CSS selector for the form and mark each question block `data-pa-group`, with `data-pa-answered="1"` on the ones the server already counted. The drawing then follows the student's typing live. The picture's title is deliberately hidden until the last question — the surprise is the point of the whole feature. {% endcomment %} {% if progress_art %}
