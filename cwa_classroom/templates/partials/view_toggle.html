{% comment %} Reusable list / grid view toggle for class listings. Usage: {% include "partials/view_toggle.html" with container_id="my-classes" storage_key="cwa-view:teacher-classes" %} Params: container_id (required) – id of the element wrapping the cards. That element must also carry `data-cwa-container` and start with either `cwa-grid` or `cwa-list`. storage_key (required) – localStorage key used to remember the choice. default_view (optional) – "grid" (default) or "list". Used only when nothing is stored yet; keep it in sync with the class the container is rendered with server-side. The container switches between a responsive tile grid (`cwa-grid`) and a single column of full-width rows (`cwa-list`). Cards tagged `cwa-card--split` lay their `.cwa-card-main` / `.cwa-card-aside` children out horizontally in list view. {% endcomment %}
