{% comment %} Per-part breakdown of a part-graded answer — a fill-in-the-blank sentence or a table of values, where one question asks for several values and is marked one value at a time (see maths/partial_credit.py). Receives: data — the blob written by ``PartialGrade.as_answer_data()``. Worksheets and homework store it on the answer row's ``answer_data``; the quiz stores it in the attempt's review payload. One partial explains a partly-right answer on every one of those pages. earned — points this answer earned (optional) possible — points the question was worth (optional). Both, or neither: half a fraction is worse than none. Renders nothing unless ``data`` carries a parts list, so a template can include it beside any answer without first asking what type the question was.
