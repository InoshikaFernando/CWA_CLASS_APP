{% comment %} The shared coding window: editor on the left, console (or live preview) on the right. Behaviour lives in static/js/code_window.js, styles and CodeMirror in coding/partials/_code_window_head.html — include that once in the page head. Parameters (via {% include ... with %}): cw_id REQUIRED. Unique per window on the page — ids are derived from it, and a page may host several windows. cw_run_url REQUIRED for cw_mode="run". Endpoint the Run button POSTs {language, code, stdin, …} to. cw_mode "run" (console) or "preview" (HTML/CSS iframe). Default run. cw_language Language slug sent in the POST body. cw_cm_mode CodeMirror mode: python / javascript / htmlmixed / css. cw_filename Filename shown in the editor's title bar. cw_starter Starter code (run mode). cw_starter_html Starter HTML (preview mode). cw_starter_css Starter CSS (preview mode). cw_exercise_id Optional — sent as exercise_id so the endpoint can resolve the exercise (e.g. for a browser-sandbox language). cw_expected_output Optional — when set, a run reports whether stdout matched. cw_lang_label Language name shown beside the heading. Default cw_language. cw_title Left toolbar heading. Default "Code". cw_height CSS height of both panels. Default 480px. cw_hide_stdin Truthy to drop the stdin box (run mode). cw_hide_reset Truthy to drop the Reset button. cw_read_only Truthy for a look-but-don't-touch editor. cw_extra_code Optional snippet; adds a button that loads it into the editor (the builder preview passes the reference solution). cw_extra_label Label for that button. Default "Load solution". cw_textarea_name Optional form field name for the editor's textarea, so the code posts with the surrounding form (homework, worksheet session). Omit for read-only/try-it windows. cw_mark_complete Truthy to send mark_complete:true with the run. Pages that own grading elsewhere (homework, worksheet session) leave it off — a Run there is feedback, never a submission. {% endcomment %}
