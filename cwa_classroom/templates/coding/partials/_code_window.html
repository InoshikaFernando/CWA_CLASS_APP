{% comment %} The shared coding window: editor on the left, console (or live preview) on the right. A preview window can carry up to three panes — index.html, style.css and (with cw_show_js) script.js — which the browser assembles into one page. Behaviour lives in static/js/code_window.js, styles and CodeMirror in coding/partials/_code_window_head.html — include that once in the page head. Parameters (via {% include ... with %}): cw_id REQUIRED. Unique per window on the page — ids are derived from it, and a page may host several windows. cw_run_url REQUIRED for cw_mode="run". Endpoint the Run button POSTs {language, code, stdin, …} to. cw_mode "run" (console) or "preview" (HTML/CSS iframe). Default run. cw_language Language slug sent in the POST body. cw_cm_mode CodeMirror mode: python / javascript / htmlmixed / css. cw_filename Filename shown in the editor's title bar. cw_starter Starter code (run mode). cw_starter_html Starter HTML (preview mode). cw_starter_css Starter CSS (preview mode). cw_starter_js Starter JavaScript (preview mode, with cw_show_js). cw_show_js Truthy for a third pane, script.js, injected before so it runs against the parsed page. Off for an exercise, which seeds a single document from one field. cw_exercise_id Optional — sent as exercise_id so the endpoint can resolve the exercise (e.g. for a browser-sandbox language). cw_expected_output Optional — when set, a run reports whether stdout matched. cw_lang_label Language name shown beside the heading. Default cw_language. cw_title Left toolbar heading. Default "Code". cw_height CSS height of both panels. Default 480px. cw_hide_stdin Truthy to drop the stdin box (run mode). cw_hide_reset Truthy to drop the Reset button. cw_read_only Truthy for a look-but-don't-touch editor. cw_extra_code Optional snippet; adds a button that loads it into the editor (the builder preview passes the reference solution). cw_extra_label Label for that button. Default "Load solution". cw_textarea_name Optional form field name for the editor's textarea, so the code posts with the surrounding form (homework, worksheet session). Omit for read-only/try-it windows. cw_mark_complete Truthy to send mark_complete:true with the run. Pages that own grading elsewhere (homework, worksheet session) leave it off — a Run there is feedback, never a submission. cw_panes "both" (default), "editor" (no console — the problem page reports test-case results its own way) or "console" (no editor — the Scratch exercises edit in a Blockly workspace and hand their generated code to runWith()). cw_autocomplete Truthy for Ctrl-Space word completion. cw_hide_run Truthy to drop the Run button (the page has its own). cw_run_label Alternative Run button label. cw_hide_toolbar Truthy to drop the editor column's toolbar (a page that keeps its own Run/Reset above the window). cw_hide_console_toolbar Same for the console column's Output/Clear bar. cw_external_run Truthy so Run (and Ctrl-Enter) dispatch `code-window:run` instead of posting — for a page that owns the request. cw_hide_verdict Truthy to drop the match/mismatch line, for a page that reports the result its own way (the exercise page's score card) and would otherwise say it twice. A run dispatches `code-window:result` on the window root, carrying the response, so a page can drive extra UI of its own (the exercise page's score card and mark-complete button) without the window knowing about exercises. {% endcomment %}
