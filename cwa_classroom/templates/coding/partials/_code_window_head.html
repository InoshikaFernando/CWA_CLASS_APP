{% load static %} {% comment %} Assets for the shared coding window (templates/coding/partials/_code_window.html). Include this ONCE in a page's {% block extra_head %}, however many windows the page renders. It loads CodeMirror 5 (vendored, see below), defines the window's styles, and loads code_window.js, which mounts every window on the page. Every page that wanted an editor used to paste these nine CodeMirror tags into its own head; they now live here so a version bump is one edit. {% endcomment %} {% comment %} CodeMirror 5.65.16, vendored under static/vendor/codemirror/ rather than pulled from cdnjs. The worksheet builder loads this partial, and the builder has been down this road before: SortableJS came from a CDN, the fetch failed, and because the library is used at the top of the page's IIFE the ENTIRE builder went dead — no search, no adding questions, no save. A coding window that fails to load should degrade to a plain textarea, not take its host page with it, and the surest way there is not to depend on someone else's uptime. coding/tests/test_code_window.py fails the build if a CDN URL creeps back in here, and worksheets' TestBuilderAssetsAreSelfHosted covers the builder page it is loaded into. {% endcomment %}
